A single joke about office life, one line, 196 characters: an inbox with
4,000 unread emails, a declaration of email bankruptcy, and an
out-of-office reply that chooses peace and redirects all urgency to the
printer down the hall. `main.py` writes the line to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

## Run it

```sh
python3 main.py
```
